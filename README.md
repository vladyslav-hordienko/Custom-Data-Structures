# Custom Data Structures

Java implementations of a generic array-backed stack and a circular linked list, created without relying on built-in collection implementations for their core behaviour.

## Stack
- Generic `Stack<E>` interface.
- Array-backed `StackArr<E>` implementation.
- `push`, `pop`, `peek`, `empty`, `full`, and display operations.

## Circular linked list
- Custom node structure with head/tail tracking.
- Add at beginning/end and insert after a node.
- Retrieve a node by index.
- Remove one or all matching values.
- Preserve the circular link between tail and head.

## What I practised
Generics, interfaces, arrays, linked structures, references/pointers, boundary conditions, traversal, encapsulation, and implementing data structures from first principles.
